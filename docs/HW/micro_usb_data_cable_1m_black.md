# Micro USB Data Cable 1m Black

## What it is

This is a `micro USB` data cable, `1 m` long, black. In the project it is mainly a utility part for programming, serial debugging, and bench power.

## Verified key facts

- Connector type: `micro USB`
- Length from invoice: `1 m`
- Color from invoice: black
- Role: data and power cable

## Why it is useful in the project

- Connects the ESP32 board to the computer for flashing firmware
- Can provide stable USB power during desk testing
- Useful for serial console debugging

## What to watch during the project

- Some USB cables are charge-only; those will fail for data
- Poor-quality cables can cause random reset or upload issues
- Use only for low-voltage USB power, not for direct high-current loads

## Best use in this project

- Firmware upload
- Serial monitoring
- Temporary bench power

## Bad use in this project

- Permanent wiring inside the enclosure
- Any use where the cable will be bent or pulled repeatedly
