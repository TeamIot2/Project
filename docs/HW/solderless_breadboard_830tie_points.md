# Solderless Breadboard 830 Tie Points

## What it is

This is a reusable solderless prototyping board with `830` tie points. It is the fastest way to test wiring before you commit anything to solder or a more permanent board.

It is the correct choice for first wiring checks, not for the final install.

## Verified key facts

- Product type: solderless prototyping breadboard
- Item size from invoice: `830` tie points
- Use: temporary circuit assembly without soldering
- Typical grid: `2.54 mm` / `0.1 in`
- Typical layout: split contact rows plus power rails

## Why it is useful in the project

- Lets you test ESP32 sensor wiring without soldering
- Makes sensor bring-up much safer for a beginner
- Easy to change when a pin assignment is wrong

## What to watch during the project

- Contacts are only held by spring pressure, so they can loosen over time
- Bad seating creates intermittent bugs that look like software problems
- It is not a final mechanical solution

## Best use in this project

- First prototype wiring
- Sensor validation
- Quick debugging on the desk

## Bad use in this project

- Final demo hardware that gets moved around
- Anything that must survive vibration or transport
